I used Kai Periera's starter project tutorial on stasis to make this RP2040 devboard.
I made it because I wanted to develop my skills and make more stuff. I also want to get more soldering practice.
<img width="1680" height="1050" alt="image" src="https://github.com/user-attachments/assets/c0a8f467-eae3-4f3b-b56c-9d6d6739d19d" />
<img width="1680" height="1050" alt="image" src="https://github.com/user-attachments/assets/f487db48-2e19-47d0-9b5a-765d9478fe41" />
This is the 3d case that I designed to hold and protect it. It has the word "Cryptoblade"- my gamer tag -etched on to the top.
It openes and closes using a sliding lid and is held in place with cylindrical 5x5x3mm neodynium magnets.

Once I get the parts I will:
1. Solder everything together
2. Glue the magnets into the case.
Then I'm done!
